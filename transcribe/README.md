# Kevin Transcribe · 随声记（手机试用版 0.2）

独立地址：`/FE-vocabulary/transcribe/`。静态 PWA，使用当前 GitHub Pages 发布。
无需 Python、后端、API Key 或订阅。网页界面适配手机，可添加到 iPhone 主屏幕。

## 功能

- 导入系统录音，IndexedDB 本地保存原音频与文字。
- MediaRecorder 前台直接录音（最长 5 分钟）；后台自动停止，依赖浏览器支持。
- Worker 内使用 Transformers.js 3.8.1 / Whisper tiny 多语言量化模型，WASM 单线程转写。
- 英文、中文、自动语言；单文件上限 200 MB / 3 小时，按 60 秒逐段读取与转写，完成一段即保存进度，可暂停续转。此上限不是 iPhone 实机性能保证。
- 时间戳回听、逐段修改、手动说话人、TXT / SRT / JSON 文字备份、原音频导出。
- 页面缓存只管理自己的前缀；同时收窄原背词 SW 的缓存清理和拦截范围。
- ChatGPT 分析路径：复制完整转录和分析提示，打开 ChatGPT 手动粘贴发送；也可导出分析 TXT 后自行上传。不会自动传输录音或转录。
- 无内置 AI 会议纪要、自动分人、Word 导出；不等同于桌面 v0.3 的全部功能。

## 数据与网络

音频不上传，推理在浏览器完成。首次下载程序及模型需联网，文件来自 jsDelivr 和
Hugging Face，模型资产约百 MB 级。浏览器可能清理缓存，不保证离线可用。
“英文示例”下载公开的 Transformers.js 文档 JFK WAV，用于用户自测。
源代码公开，不包含用户的录音或转录。不要在公开仓库提交真实工作录音。

本机存储可能被浏览器回收，请定期导出。Safari 与主屏幕模式可能使用不同存储。
转写时保持前台；后台挂起、设备内存不足或锁屏可能中断。
停止任务保留原音频和已完成片段；当前未完成的一分钟需要重做。分段边界的词句需回听核对。
重新转写前会提示备份旧结果。JSON 只备份文字，不包含音频。

## 验证

`node --test tests/transcribe.test.mjs`（从仓库根目录）。
既有背词回归检查：`node tests/scheduler.test.cjs`。
还需用户的 iPhone Safari / 主屏幕实机验收，尤其是内存、速度与中文效果。

2026-11-08 验证：9 项转写/导出/备份/缓存/ChatGPT 提示测试通过；背词调度和语音回归测试通过。实际 Chrome 浏览器通过公开 11 秒英文音频下载、WASM 模型转写、保存和说话人编辑；复制权限缺失的手动复制回退通过。未进行 iPhone、中文、长录音或麦克风实机测试。

0.2 验证：11 项自动测试通过，包括 65 分钟进度保存/恢复与时间戳连续性；Chrome 实测 65 分钟合成 WAV 的首段、64 分钟位置和静音段按需读取与重采样通过。新版 11 秒真实语音转写及保存通过。合成长文件读取不等于完整长会议识别验收；iPhone、M4A 解码和整小时实际识别仍需实机验证。
